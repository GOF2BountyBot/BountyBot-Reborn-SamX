# TASK_0007 — T7 — Turret weapons: auto + manual + mode switch

Integrate the three turret subtypes into the tick-resolver firing pipeline established by T5, gating the auto-vs-manual-vs-inert dispatch on the `automatic` and `subtype` fields and adding ship-wide `manual_turret_mode` gating for the manual branch.

## Deliverables

### Subtype discrimination (§6.3)

The dispatcher for every equipped turret on a `ShipLoadout` must classify by:

| Discriminator | Behavior |
|---|---|
| `subtype == "plasma-collector"` | Inert. No cooldown tick, no fire eval, no event, no damage. Loaded for fidelity per §7.9. |
| `automatic == true` (no `subtype`) | Auto-turret path below. |
| `automatic == false` (no `subtype`) | Manual-turret path below. |

Neither auto nor manual turrets carry an explicit `subtype` field — only plasma-collectors do. Dispatch on `automatic` for the auto-vs-manual split.

### Auto turrets (`automatic: true`)

- **Fires additively alongside primaries.** Auto turrets do not compete for the primary slot. `manual_turret_mode` does NOT affect auto turrets — they always fire on their own cooldown regardless of mode.
- **Cooldown:** independent per-turret `loading_speed_ms`, decremented at Appendix B phase 1. An 8-turret ship maintains 8 independent counters.
- **Range gate (§6.1):** fires only when `current_distance ≤ range_m`.
- **Accuracy (single value per ship per tick):**
  ```
  auto_turret_acc = clamp(pilot_turret_acc × AUTO_TURRET_ACCURACY_MULTIPLIER,
                          ACCURACY_CLAMP_MIN, ACCURACY_CLAMP_MAX)
  ```
  Computed **once** per combatant per tick and reused across all of that combatant's auto turrets. This is both a perf optimization and a correctness statement — no per-turret variation.
- **Cloak override inheritance:** when the target is cloaked, `pilot_turret_acc = CLOAK_SET_VALUE` (T4 already applied the override). The 0.85 multiplier then compounds → ~0.2125, re-clamped.
- **PrimaryWeaponMod does NOT apply** (§7.8). Turret stats consume the seed `damage_per_shot` and `loading_speed_ms` directly. Do NOT route turret damage through the `effective_damage_per_shot` field T5 computes for primaries.
- **Damage:** call into T3's damage-application helper (which handles PvC DR + the shield → armour → hull stack).
- **Event:** one `weapon_fire` per shot at phase 7, payload `{slot, subtype: "auto", weapon, hit, accuracy}`.

### Manual turrets (`automatic: false`)

Mutually exclusive with primaries via the ship-wide `ShipLoadout.manual_turret_mode: bool`:

- **`manual_turret_mode = false` (default — "primary mode"):** primaries fire normally; **manual turrets do NOT fire** this fight. They remain equipped but inert (no cooldown tick, no fire eval, no event).
- **`manual_turret_mode = true` ("turret mode"):** **primaries do NOT fire** this fight (see "Primary suppression" below); manual turrets fire per the rules here. Auto turrets are unaffected.

When firing (mode = true):

- **Accuracy:** `pilot_primary_acc` — the full §5 layered formula INCLUDING thruster bonus. The 0.85 auto-turret multiplier does NOT apply. Cloak override still applies when target is cloaked (already handled by T4).
- **Cooldown:** independent per-turret `loading_speed_ms`. A ship with N manual turrets fires up to N shots per cycle, each rolled independently against `pilot_primary_acc`.
- **Range gate (§6.1):** `current_distance ≤ range_m`.
- **PrimaryWeaponMod does NOT apply** (§7.8 explicitly excludes all turrets).
- **Damage:** call into T3's damage-application helper.
- **Event:** one `weapon_fire` per shot at phase 7, payload `{slot, subtype: "manual", weapon, hit, accuracy}`.

### Primary suppression when `manual_turret_mode = true` (§6.3)

This is a **change to T5's primary fire-eval phase**. Surface area is one conditional in the existing T5 code path:

- At phase 3 (fire eval), if `loadout.manual_turret_mode == true`, primaries skip the fire evaluation entirely — no accuracy roll, no `weapon_fire` event, no cooldown reset.
- **Primary `cooldown_remaining_ms` STILL decrements** at phase 1. Suppression gates the fire-eval, not the cooldown tick. Phase-1 has no mid-fight mode toggle, but preserving correctness here is cheap and forward-ready.
- Auto turrets and manual turrets are unaffected by each other's firing rules.

### Plasma-collector turret (`subtype: "plasma-collector"`)

Inert. Skip entirely in the dispatcher: no cooldown decrement, no fire eval, no event, no damage. `dps: 0` in seed data. Equippable for fidelity only (§7.9).

### Builder slice + builder-fed integration test (turret slice — locked Q3)

The `loadout_builder.py` DB-backed wire-up is distributed across T6–T8; T7 owns the turret slice.

- **`LoadoutBuilder` maps turret `damage_per_shot` / `loading_speed_ms` / `range_m`** from seed (today the builder constructs turret `WeaponStats(name, dps)` only), plus the turret discriminators `automatic` and `subtype` (`"plasma-collector"`).
- **Ship a real builder-fed integration test** that runs a fight from a builder-produced loadout (not hand-built fixtures) and asserts auto/manual turrets fire with real cadence/range and the plasma-collector stays inert.

## Test surface

Max 2 mocks per test. Prefer real `ShipLoadout` / weapon dataclasses with deterministic RNG seams.

1. **Auto turret cadence** — weapon with `loading_speed_ms = 500`, target stationary in range: fires every 50 ticks at expected accuracy.
2. **Auto turret range gate** — at `current_distance > range_m` does NOT fire; at the boundary (`==`) it does.
3. **Auto turret multi-turret accuracy share** — 8-turret ship: all 8 fire at the same `auto_turret_acc` value within a single tick.
4. **Auto turret cloak override compounds** — target cloaked → `pilot_turret_acc = CLOAK_SET_VALUE = 0.25` → auto turret fires at `0.25 × 0.85 ≈ 0.2125` (re-clamped).
5. **Manual turret — mode = false** — manual turret equipped, `manual_turret_mode = false`: manual turret does NOT fire; primaries DO fire (regression check that T5 default mode still works).
6. **Manual turret — mode = true** — `manual_turret_mode = true`: primaries do NOT fire; manual turret fires at `pilot_primary_acc` (NOT multiplied by 0.85).
7. **Manual turret thruster bonus applies** — close range with thruster equipped, mode = true: manual turret accuracy = full thruster-boosted `pilot_primary_acc`. (Counter-intuitive given the naming — manual turret uses the *primary* variant per §6.3.)
8. **Manual turret — N turrets independent** — N manual turrets equipped, mode = true: up to N shots per fire cycle, each rolled independently.
9. **Auto turret unaffected by mode** — `manual_turret_mode = true` does NOT suppress auto turret firing.
10. **PrimaryWeaponMod isolation — auto** — ship with PrimaryWeaponMod (`damage_pct = +20`) + auto turret: turret damage is the seed `damage_per_shot`, NOT scaled.
11. **PrimaryWeaponMod isolation — manual** — same setup, mode = true: manual turret damage is NOT scaled.
12. **Plasma-collector inertness** — equipped, ticks elapse, NO `weapon_fire` event ever emitted; no cooldown decrement observed.
13. **Primary cooldown decrements under mode = true** — even when fire-eval is suppressed, primary `cooldown_remaining_ms` continues to tick down.
14. **Event payload contract** — `weapon_fire` events for auto vs manual turrets carry distinct `subtype` labels (`"auto"` / `"manual"`) per §12.

## Acceptance criteria

- All T1–T6 tests still pass (no regression).
- A fight with both auto turrets and primaries produces additive damage — turrets fire alongside primaries, not in place of them.
- `manual_turret_mode = true` suppresses primary firing AND enables manual turret firing in the same fight.
- Auto turret accuracy = `clamp(pilot_turret_acc × AUTO_TURRET_ACCURACY_MULTIPLIER, ACCURACY_CLAMP_MIN, ACCURACY_CLAMP_MAX)`, single value per tick across all auto turrets on a given combatant.
- Manual turret accuracy = `pilot_primary_acc` (full §5 with thruster; cloak overrides if active).
- PrimaryWeaponMod does not scale any turret damage (auto, manual, or plasma-collector).
- Plasma-collector turret is fully inert — no events, no cooldown tick, no damage.
- `weapon_fire` payloads carry distinct turret subtype labels per §12.
- Primary `cooldown_remaining_ms` continues to decrement even when suppressed by `manual_turret_mode = true`.

## Risk / notes

- **`automatic: bool` is the discriminator for auto vs manual** (§6.3). Neither subtype carries a `subtype` field; only plasma-collectors do. Easy mistake: treating absent `subtype` as a default rather than dispatching on `automatic`.
- **One auto-turret accuracy value per ship per tick** (§6.3). This is BOTH a perf optimization AND a correctness statement — no per-turret variation. Compute `pilot_turret_acc` once per tick per combatant; apply the 0.85 multiplier once; reuse the result for every auto turret on that ship.
- **Manual turret uses `pilot_primary_acc`, not `pilot_turret_acc`** (§6.3 "treated as a primary"). Counter-intuitive given the variable naming, but explicit in the spec: manual turret fire INCLUDES the thruster bonus; auto turret fire does NOT.
- **Cloak override still applies to manual turrets** (§6.3 inherits the §5 layered formula → cloak supersedes the layered result entirely). T4 already applies the override to `pilot_primary_acc`; T7 just consumes it.
- **Primary suppression under mode = true is a CHANGE to T5's primary phase** — gate the fire-eval, NOT the cooldown decrement. Single conditional; minimal churn to T5 code.
- **PrimaryWeaponMod-modified stats live on primaries only** (§7.8). Turret stats consume the seed `damage_per_shot` / `loading_speed_ms` directly. Do NOT route turret damage through T5's `effective_damage_per_shot` field.
- **Plasma-collector turret IS in the turret seed-data** with `dps: 0` and `subtype: "plasma-collector"`. Skip it in the dispatcher — do NOT treat absent firing as a bug to fix.
- **PvC DR applies to turret-inflicted damage** like any other source — T3's damage-application helper handles this; T7 just calls into it.
- **Appendix B phase order is canonical.** T7 touches phase 1 (cooldown decrement — add the turret counters), phase 3 (fire eval — add auto + manual branches, gate primary branch on `manual_turret_mode`), phase 4 (damage application — turret hits go through the T3 helper), phase 7 (event emission — preserve C1-before-C2 ordering for turret events too).
